# IB ESS Paper Generator

Practice Paper 1 (case study) and Paper 2 for IB DP Environmental Systems and Societies (first assessment 2026), SL and HL.
All case studies, questions and data are original; places in Paper 1 are fictional.

- Paper 1: resource booklet + questions — SL 35 marks / 1 h, HL 70 marks / 2 h
- Paper 2: Section A (40) data-based; Section B structured essays — SL 1 of 2, HL 2 of 3 — (c) marked with markbands

Files: `index.html`, `app.js`, `data/*.js` (question banks, figure helpers), `api/mark.js` (server-side marking for "Upload for feedback").

## Vercel environment variables (for feedback)
- `CODECRAFT_API_KEY` — Gemini API key
- `CODECRAFT_BASE_URL` — `https://generativelanguage.googleapis.com/v1beta/openai`
- `CODECRAFT_MODEL` — `gemini-3.8-flash`
